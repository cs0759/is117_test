# Meaning by Design

## A Mini Textbook on Persuasion, Branding, and Visual Language

Every product can be presented in more than one way. This guide uses the plain white T-shirt as a recurring thought experiment, then connects its lessons to branding, visual history, and AI-assisted work.

The chapters move from individual ideas to a practical synthesis. Read them in order the first time. On later visits, use the questions, tables, and case study as tools for planning a project or reviewing an AI-generated result.

## How to Use This Guide

As you read, separate the physical product from the meaning built around it. Notice what each example asks the audience to feel, imagine, or do. Then test the idea against the questions at the end of each chapter.

When applying the guide to your own project, begin with the audience and intended response. Choose a meaningful identity or archetypal direction, select a visual language that supports it, and write down the constraints before asking AI to help. Review the result as an editor and decision-maker, not as a passive recipient of fluent text or attractive output.
